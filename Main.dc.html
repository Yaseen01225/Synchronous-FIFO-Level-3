Definition & Purpose
A synchronous FIFO is a First-In-First-Out buffer driven by a single clock. This version adds early-warning flags and counts every request it had to turn away.
✓
Almost-full and almost-empty thresholds
✓
Counts writes rejected when full and reads rejected when empty
✓
Parameterized width, depth and thresholds

Rejected-Operation Counters
rejected_writes + 1 when
wr_en && full && !(rd_en && !empty)
rejected_reads + 1 when
rd_en && empty && !(wr_en && !full)
1
A write is not counted if a read frees a slot in the same cycle, and the reverse for reads.
2
Saturating: at 8'hFF (255) a counter holds instead of wrapping to 0.
Key Takeaways
✓
Almost flags warn at 6 and 2, before full or empty
✓
Rejected requests are counted, never silently lost
✓
Change DEPTH together with ADDR_WIDTH and COUNT_WIDTH
Conclusion
status_fifo extends a basic synchronous FIFO with threshold flags and saturating counters for rejected writes and reads. A controlling design can slow down early and see how many requests were turned away.
